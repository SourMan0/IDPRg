# IDPRg — predicting IDR radius of gyration from sequence

This repo predicts the radius of gyration (Rg) of intrinsically disordered
proteins/regions (IDRs) from their amino-acid sequence, using four parallel
feature-extraction pipelines — hand-crafted **physical features**, and three
protein language model embeddings (**ESM-2**, **ProtBERT**, **UniRep**) — and
then asks *which residues/motifs drive Rg* via sliding-window occlusion,
sequence logos, and SHAP/coefficient interpretation.

All four pipelines share the same raw dataset and the same downstream shape:

```
raw sequences + Rg  →  feature extraction  →  regression sweep (5 seeds × models)
                     →  pick best config    →  refit interpretation model
                     →  sliding-window occlusion  →  sequence logos / directionality plots
```

If you only need to know exactly which file produced which figure for the
**ESM + physical-features leak-fix re-run** (the most recent work, see the
`Redid everything to account for leaky pca/standardization` commit), read
[OUTPUTS_MANIFEST.md](OUTPUTS_MANIFEST.md) — it tracks every artifact stage by
stage, old vs. new. This README is the wider map: what every folder is for and
how to regenerate the whole study from scratch.

## Study design in one paragraph

`data/rawData.csv` holds 167 IDR sequences with experimentally- or
computationally-measured Rg, plus solution conditions (pH, salts, buffers).
`cleanData.py` turns this into `training/all_points.csv` (167 rows) and
`training/inliers.csv` (163 rows, 4 outliers at indices 114/125/137/163
excluded) with 20 target columns per row: raw Rg, Rg normalized by 3 different
scaling exponents (0.421 / 0.5 / 0.406, i.e. Rg/N^ν), and each of those with
pH and/or buffer effects regressed out. Each of the four pipelines extracts a
feature matrix from the sequences, sweeps 5 regressors (Linear, Ridge, Lasso,
Kernel Ridge, GPR) × 5 random seeds × several train/test splits against all 20
targets, then picks the best (feature-set, model) combination and interprets
it — either via linear-model coefficients/SHAP (physical features) or via
sliding-window occlusion + sequence-logo motif discovery (embeddings).

**Leakage note:** an earlier round of this pipeline fit `StandardScaler`/`PCA`
on *all* 167 points before any train/test split, leaking test-point statistics
into "held-out" evaluation. Every stage listed above has since been rewritten
so `StandardScaler`+`PCA`+model live together in a single `sklearn.Pipeline`
that is only ever fit on the training fold (see the `Pipeline([...])` you'll
see repeated throughout `doAllRegressions.py` and the `*3.py`/`*3St.py`/
`*_pipeline.joblib` scripts). Files/folders suffixed `_leaky`, `OLD`, or
`ALSOOLD` are the pre-fix artifacts, kept only so old vs. new numbers can be
diffed — **don't use them as inputs to anything new.**

## 2. Raw data & shared labels

| Path | What it is |
|---|---|
| `data/rawData.csv` | Source-of-truth: 167 rows, one IDR per row — sequence, Rg/Ree/Rh, solution conditions (salts, pH, buffer, DTT, etc.), whether experimental or computational, and a source URL. Hand-curated; not regenerated by any script. |
| `cleanData.py` | Reads `data/rawData.csv`, keeps rows with both a sequence and an Rg, computes 3 normalized-Rg variants (Rg / N^0.421, N^0.5, N^0.406) and writes `training/all_points.csv` + `training/inliers.csv`. **Run this first.** |
| `regressOut.py` | Regresses pH and/or buffer-solution effects out of Rg via `LinearRegression`, producing the "w/pH regressed out" / "w/buffer regressed out" / "w/experimental pH regressed out" / "w/experimental buffer regressed out" target columns that end up in `training/all_points.csv` / `inliers.csv`. Mostly exploratory/commented-out driver code — treat as the reference implementation for those columns, not a script you need to rerun. |
| `writeCsv.py` | Tiny `write_csv(filename, Xs, Ys, Xname, Yname)` helper shared by `cleanData.py`/`regressOut.py`. |
| `training/all_points.csv` | **167 sequences × 20 Rg target columns.** The canonical label table every pipeline reads. |
| `training/inliers.csv` | Same but the 163-row subset (4 outliers dropped) used for the final interpretation refits. |
| `data/all*.csv`, `data/inliers*.csv` (root `data/`) | Earlier/alternate normalizations of the same labels (`allRaw`, `allNormalized`, `allNormalizedNaive`, `allNormalizedWithInliers`, and the `inliers*` equivalents) consumed by `regressOut.py` and some of the UniRep scripts. Superseded by `training/*.csv` for anything new. |

Target-column naming you'll see everywhere downstream: `"Rg (nm)"` = raw,
`"Rg normalized w/{0.421,0.5,0.406}"` = Rg/N^ν, and each of those with
`"... w/pH regressed out"` / `"... w/buffer regressed out"` /
`"... w/experimental {pH,buffer} regressed out"` appended. `"Points"` is
either `"All"` (167) or `"Inliers"` (163).

## 3. Shared regression harness

| Path | What it is |
|---|---|
| `doAllRegressions.py` (root) | The shared sweep engine: `evaluate_models_rmse(...)` builds `Pipeline([StandardScaler, PCA(n_components=d), model])` for Linear/Ridge/Lasso/Kernel-Ridge/GPR, runs `GridSearchCV` for hyperparameters, and reports train/test R²/RMSE for a given (features, targets, seed, split) combo — with PCA dimension capped at `0.8 * n_train` so it always fits inside every CV fold. **This is the file that fixes the PCA leak** across all pipelines. |
| `esmScripts/doAllRegressions.py`, `physicalFeatures/doAllRegressions.py` | **Identical copies** of the root file — present so each pipeline's scripts can `import doAllRegressions` while running with that subfolder as the working directory. | `Regressions/{linear,ridge,lasso,kernelRidge}Regression.py` | Standalone single-model reference implementations (`Pipeline([StandardScaler, model])`, one `train_test_split`) — useful for a quick sanity check on one feature file, not used by the batch sweeps above. |
| `results/unirep_allRawTestSize0.2LinearResults.txt` | An early one-off sanity-check log from running `LinearRegression` directly on raw (non-PCA'd) UniRep embeddings — illustrates why PCA is needed (test R² is wildly negative on the 1900-d raw features). |

| `physicalFeatures/protein_features3St.csv` | One iteration earlier (before the final feature set settled); kept for provenance. |
| `physicalFeatures/extractFeaturesFromPoints.py`, `extractFeaturesFromPoints2St.py`, `extractFeaturesFromPointsSt.py`, `extractFeaturesFromSequences2.py` | Earlier iterations of the extractor (different feature sets / earlier label files). Superseded by `extractFeaturesFromPoints3St.py`; their outputs live in `physicalFeatures/oldFeatures/` and `alsoOldFeatures/`. |
| `physicalFeatures/doRegressions3.py` | Current sweep: reads `protein_features3St2.csv`, wraps `Pipeline([StandardScaler, model])`, runs `doAllRegressions.evaluate_models_rmse` across 5 seeds → `pfeatureLosses{1..5}St3.csv` (8-column schema) + `pfeature_sweep.log`. |
| `physicalFeatures/doFeatureRegressions.py`, `doMoreFeatureRegressions.py` | Earlier sweep variants over earlier feature CSVs; superseded by `doRegressions3.py`. |
| `physicalFeatures/pfeatureLosses{1..5}St3.csv` | **Current** sweep results (leak-free). `pfeatureLosses{1..5}St3_leaky.csv` and the copies under `losses/` are the archived pre-fix numbers. |
| `pfeaturesInterpretation/interpretFeatures2.py` | Current interpretation script: refits Ridge/Lasso/Linear/Kernel-Ridge/GPR via `GridSearchCV(Pipeline([StandardScaler, model]))` on the 163 inliers for a chosen target, plots sorted standardized coefficients (Ridge is the journal headline figure), partial-dependence "directionality" curves for KRR/GPR, and SHAP beeswarm plots for KRR. |

| `pfeaturesInterpretation/target_0p406/`, `target_0p5/` | Full figure sets (Ridge/Lasso/Linear coefficients, KRR/GPR directionality, KRR SHAP beeswarm + importance) rerun for the `Rg normalized w/0.406` and `Rg normalized w/0.5` targets respectively — same script, different `--target`/target selection inside `interpretFeatures2.py`. |
| `pfeaturesInterpretation/*_leaky.pdf/.png` | Archived pre-fix figures for comparison. |
| `interpretFeatureLosses.py`, `interpretFeatureLossesSt.py`, `interpretFeatureLossesSt3.py` (root) | Scripts that scan the `pfeatureLosses*.csv` sweep outputs across all 5 seeds and print/plot the best (target, model) combinations — one version per feature-extraction iteration (`""`, `St`, `St3` matches the `extractFeaturesFromPoints*.py` suffix it was written against). Use the `St3` version against the current `pfeatureLosses*St3.csv` files. |

## 5. Pipeline B — ESM-2 embeddings

Canonical chain (current, leak-free):

```
training/all_points.csv
  → esmScripts/makeESMPoints.py            → esmScripts/esm_embeddings/esm{6,12}layer.pt
  → esmScripts/esmRegressionsAllSeeds.py    → esmScripts/esmLosses{1..5}.csv, sweep.log
  → esmScripts/selectBestConfigs.py         → esmScripts/best_configs.csv
  → interpretingESM/prepareForInterpretation.py → lasso_pipeline.joblib, krr_pipeline.joblib
  → interpretingESM/tryingDifferentType2.py     → allEffects4.pkl, allFragments4.pkl  (sliding-window occlusion)
  → interpretingESM/findMotifs3.py              → baseline_logos_fragment_sizes.pdf  (sequence-logo motifs)
  → interpretingESM/exploringFGNups.py          → fgnup_*.pdf  (FG-Nup case study)
```

| Path | What it is |
|---|---|
| `esmScripts/makeESMPoints.py` | Runs `facebook/esm2_t6_8M_UR50D` (the 6-layer ESM-2 model) over every sequence in `training/all_points.csv`, mean-pools each hidden-state layer, and stacks all layers → `esm_embeddings/esm6layer.pt` (a `(167, 7, 320)` tensor: 6 transformer layers + embedding layer). An analogous run against the 12-layer ESM-2 checkpoint produces `esm12layer.pt` `(167, 13, 480)`. **Run once; embeddings don't change across seeds/models.** |
| `esmScripts/esm_embeddings/esm6layer.pt`, `esm12layer.pt` | The raw per-layer mean-pooled embeddings — input to every downstream ESM script. |
| `esmScripts/esmRegressionsAllSeeds.py` | **Current sweep.** Loads the raw `.pt` embeddings (not pre-baked PCA), and for every (target column × ESM model × layer × PCA dim × regressor × points-subset × seed) runs `doAllRegressions.evaluate_models_rmse`, which wraps `StandardScaler+PCA+model` in one `Pipeline` fit only on the train fold. Parallelized across a `ProcessPoolExecutor` (BLAS pinned to 1 thread/worker) so the full 5-seed sweep finishes overnight instead of ~3 days. Writes `esmLosses{1..5}.csv` (10-column schema) and streams progress/ETA to `sweep.log`. |
| `esmScripts/esmRegressions.py` | Single-seed / non-parallel predecessor of the above; kept for reference. |
| `esmScripts/6esmPCAMake.py`, `12esmPCAMake.py` → `esmScripts/6esmPCA/`, `12esmPCA/` | **Deprecated.** These pre-computed `StandardScaler().fit_transform` + `PCA().fit_transform` over *all* 167 points before any split — the original source of the leak. No longer consumed by anything; kept only so old numbers can be diffed against the fix. |
| `esmScripts/oldData/` | Archived embeddings/CSVs from an earlier ESM extraction pass. |
| `esmScripts/selectBestConfigs.py` | Aggregates `esmLosses*.csv` across the 5 seeds × splits by mean test R², optionally filtered by `--target`/`--points`/`--regr-out`/`--model`, and writes the ranked summary to `best_configs.csv`. Use this to pick which (ESM model, layer, PCA dim, regressor) to refit for interpretation. |
| `esmScripts/esmLosses{1..5}.csv` | Current (leak-free) sweep results. `losses/esmLosses{1..5}_leaky.csv` are the archived pre-fix numbers. |
| `interpretingESM/prepareForInterpretation.py` | Refits the chosen configs as single `Pipeline([StandardScaler, PCA, Lasso])` / `Pipeline([StandardScaler, PCA, KernelRidge])` on all 163 inliers, with α (and γ for KRR) selected via `GridSearchCV` over the *whole pipeline* (so PCA is refit per inner-CV fold — no leak). CLI flags `--lasso-esm/--lasso-layer/--lasso-pca` and `--krr-*` let you point it at a different (ESM model, layer, PCA dim) once `selectBestConfigs.py` picks new winners. Current defaults: **ESM-6 layer 1, PCA=100** for both Lasso and KRR. |
| `interpretingESM/lasso_pipeline.joblib`, `krr_pipeline.joblib` | The refit pipelines — `pipeline.predict(X)` applies scaler→PCA→model in one call. **These are the models everything in §5's occlusion/motif stages consumes.** |
| `interpretingESM/esm_pca.joblib`, `lasso.joblib`, `esm_pca2.joblib`, `krr.joblib`, `*_leaky.joblib` | Deprecated separate-PCA-then-model artifacts from before the pipeline refactor; archived for diffing. `oldJoblibsAndPickles/` holds even older artifacts. |
| `interpretingESM/tryingDifferentType2.py` | Sliding-window occlusion: for each inlier sequence, slides a window of size k=1..10, masks it (replaces with a neutral token) using the live ESM-2 model, re-embeds, and asks `krr_pipeline.joblib` how predicted Rg shifts (ΔRg). Writes `allEffects4.pkl` (ΔRg per window position) and `allFragments4.pkl` (the omitted sub-sequence at each position). |
| `interpretingESM/allEffects4.pkl`, `allFragments4.pkl` | Current occlusion outputs (leak-free model). `_leaky` variants are archived. `allEffects3.pkl`/`allFragments3.pkl` come from an earlier sliding-window variant (`tryingDifferentSlidingWindow.py`/`analyzingDifferentSlidingWindow*.py`) using a different model path — preserved unchanged. |
| `interpretingESM/applySlidingWindowToAll.py`, `applyingOtherSlidingWindowToAll.py` | Alternate occlusion drivers that expect an `esm_gpr.joblib` GPR artifact that isn't produced by the current `prepareForInterpretation.py` — not part of the current reproducible chain; kept for reference (`allEffects.pkl`/`allEffects2.pkl` etc. are their stale outputs). |
| `interpretingESM/findMotifs3.py` | Loads `allEffects4.pkl`/`allFragments4.pkl`, computes weighted per-position amino-acid effects for motif lengths k (z-scored ΔRg → weight), and renders `logomaker` sequence logos split into "expansion" vs "compaction" motifs for fragment sizes 3/6/10 → `baseline_logos_fragment_sizes.pdf/.png`. This is the **final journal sequence-logo figure**. |
| `interpretingESM/findingMotifs2.py`, `findingMotifsForDeltaRg.py` | Earlier motif-discovery variants; superseded by `findMotifs3.py`. |
| `interpretingESM/baseline_logos_fragment_sizes.pdf/.png` | Current final figure. `_leaky` variant archived. `baseline_sequence_logos.pdf/.png`, `baseline_sequence_logos_all_aas.pdf/.png` are earlier/alternate logo layouts. |
| `interpretingESM/*_mean_dRg_by_residue*.pdf/.png` | Exploratory mean-occlusion-effect-per-residue plots (baseline/reference/pre-leak-fix variants) — diagnostic, not the headline figure. |
| `interpretingESM/exploringFGNups.py` | **FG-Nup case study.** Loads `krr_pipeline.joblib` directly, extracts ESM-6 layer-1 embeddings for four FG-nucleoporins (Nup98, Nup49, Nup153-NUS-domain, Nup153-NUL-domain), slides a k=3 occlusion window along each, and plots per-residue ΔRg with F/G residues highlighted (the two residues that define FG-repeats) in a 4-panel figure. Also prints each Nup's reference Rg and ΔRg range at runtime. |
| `interpretingESM/fgnup_nup98.pdf/.png`, `fgnup_nup49.pdf/.png`, `fgnup_nup153_nus_domain.pdf/.png`, `fgnup_nup153_nul_domain.pdf/.png` | Output figures from the case study above. |
| `interpretingESM/lookingAtSpecifcSequences.py`, `lookingForAtypicalSequences.py`, `sanityCheck.py`, `testingOutAnalyses.py`, `testingTheSlidingWindow.py`, `analyizingOtherSlidingWindow.py`, `tryingAnotherTypeOfSlidingWindow.py`, `allOcclusionScripts.py` | Exploratory / one-off analysis and debugging scripts used while developing the occlusion pipeline; not part of the reproducible chain above. |

`OUTPUTS_MANIFEST.md` has the exhaustive stage-by-stage artifact table for
this pipeline (and Pipeline A) — check it if a filename here isn't enough
context.

## 6. Pipeline C — ProtBERT embeddings

Same shape as the ESM pipeline, run against `Rostlab/prot_bert` instead, with
a multi-layer sweep (low/mid/high layer groups):

```
data/rawData.csv
  → protbertEmbeddingsExtractionLayers.py  → data/protbert_embeddings/protbert_{low,mid,high}.csv
  → protbertMultipleLayersPCAcalc.py        → data/protbert_embeddings/protbert_{low,mid,high}_PCA{10,20,50,100,190}.csv
  → protbertRegressionAllLayers.py          → protbertLosses/MultipleLayersLosses/protbertLosses{1..4}.csv
  → protbertLossesAllLayersInterpretation.py / protbertLossesGraphs.py → merged_losses_clean.csv, analysis plots
  → protbertBestLossesInterpretation.py     → occlusion (CIP) + sliding-window motif logos
```

| Path | What it is |
|---|---|
| `protbertEmbeddingsExtractionLayers.py` | Runs `Rostlab/prot_bert` over `data/rawData.csv`, buckets hidden-state layers into low/mid/high groups, mean-pools, and writes `data/protbert_embeddings/protbert_{low,mid,high}.csv`. |
| `protBertEmbeddingsExtraction.py` | Earlier single-output variant (`data/protBertEmbeddings2.csv`); superseded by the layers version above. |
| `protbertPcaCalc.py`, `protbertMultipleLayersPCAcalc.py` | Fit `StandardScaler`+`PCA` (10/20/50/100/190 components) on an embeddings CSV and write a `*_PCA{n}.csv` alongside it. The `MultipleLayers` version is the one used for the low/mid/high files above. |
| `protBertRegression.py` | Single-config sweep helper calling `doAllRegressions.evaluate_models_rmse` against `training/all_points.csv`/`inliers.csv`. |
| `protbertRegressionAllLayers.py` | Full sweep across layer group × PCA dim × regressor × seed → `protbertLosses/MultipleLayersLosses/protbertLosses{1..4}.csv`. |
| `protbertLosses/MultipleLayersLosses/*.csv` (`all_sorted_by_rmse.csv`, `mean_rmse_by_config.csv`, `config_stats_mean_rmse_r2.csv`, `top5_overall_summary.csv`) | Aggregation outputs consumed by the interpretation/plotting scripts below. |
| `protbertLossesAllLayersInterpretation.py`, `protbertLossesInterpretation.py` | Merge the per-seed `protbertLosses*.csv` into summary tables. |
| `protbertLossesGraphs.py` | Generates the diagnostic plots under `protbertLosses/MultipleLayersLosses/loss_plots/` (R²/RMSE boxplots, heatmaps by layer group × PCA, seed-stability plots). |

| `protbertLossesOLD/` | Archived pre-fix ProtBERT loss sweep, same internal layout as `protbertLosses/`. |

| `interpretingUnirep/unirep_pca.joblib`, `unirep_krr.joblib` (+ `_old` variants) | Interpretation-model artifacts consumed by the sliding-window/IG scripts above. |

## 8. Reproducing the study end-to-end

```bash
source esm_env/bin/activate

# 0. Labels (shared by every pipeline)
python cleanData.py

# A. Physical features
cd physicalFeatures && python extractFeaturesFromPoints3St.py && python doRegressions3.py && cd ..
python pfeaturesInterpretation/interpretFeatures2.py

# B. ESM-2
cd esmScripts && python makeESMPoints.py && python esmRegressionsAllSeeds.py && python selectBestConfigs.py && cd ..
python interpretingESM/prepareForInterpretation.py
python interpretingESM/tryingDifferentType2.py
python interpretingESM/findMotifs3.py
python interpretingESM/exploringFGNups.py

# C. ProtBERT
python protbertEmbeddingsExtractionLayers.py
python protbertMultipleLayersPCAcalc.py
python protbertRegressionAllLayers.py
python protbertLossesAllLayersInterpretation.py && python protbertLossesGraphs.py
python protbertBestLossesInterpretation.py

# D. UniRep (requires jax-unirep)
cd unirepScripts && python unirep_regressions.py && python interpretUnirepRegressions2.py && cd ..
python interpretingUnirep/prepareForInterpretation_unirep.py
python interpretingUnirep/slidingWindowEmbeddings.py
python interpretingUnirep/motifAnalysis2.py
```

Notes:
- The regression sweeps (`esmRegressionsAllSeeds.py`, `doRegressions3.py`,
  `protbertRegressionAllLayers.py`, `unirep_regressions.py`) are the slow
  steps (multi-hour to overnight); each writes a `*.log` you can tail for
  progress, and each is idempotent (checks for existing output files/embeddings
  before recomputing them).
- Several scripts assume they're run **from their own directory** (relative
  paths like `../training/all_points.csv`), per the `# Move to parent
  directory to re-make CSVs`-style comments at the top of the older ones —
  check each script's header before running it from repo root.
- Anything under a directory or filename containing `OLD`, `ALSOOLD`, or a
  `_leaky` suffix is archived output from the pre-leak-fix pipeline, kept
  only for before/after comparison — never a required input for a fresh run.
